# Shared feature catalog

- F-001 — Handheld capture: stationary object, moving phone/camera, overlapping viewpoints; no required turntable/markers.
- F-002 — Import recorded video and select frames without altering original.
- F-003 — Select frames from a live camera stream; bounded storage and run duration.
- F-004 — Import manual full-resolution still photos.
- F-005 — Automatically trigger full-resolution still capture when a useful viewpoint is reached (future).
- F-006 — Quality-aware keyframe selection with blur, overlap, new coverage, rejection reasons (future).
- F-007 — Camera calibration/intrinsics provenance; per-device/profile settings (future).
- F-008 — Interchangeable photogrammetry pipelines with per-engine capabilities and verifiable results (future; PC may have more engines).
- F-009 — Per-run diagnostic coverage, user-guided testing, privacy-preserving export, separate user verification per platform.
- F-010 — Laser-line Still/Test and eventually live mode; laser ON/OFF differentiation, dynamic per-frame laser-plane fitting, subpixel narrow stripe, geometry checks (deferred).
- F-011 — Hybrid laser + photogrammetry fusion only after both pipelines validated (deferred).

Platform implementation status is tracked in its own roadmap. These are shared requirements, not instructions to implement every item now.
